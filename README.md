# Interview Buddy 🤖

Interview Buddy is an AI-powered desktop application built with Python that combines real-time system-audio transcription with context-aware AI responses.

It uses Whisper for speech transcription and Ollama to run local language models, delivering streaming responses through a PySide6 desktop interface.

## ✨ Features

- **Real-Time Transcription:** Converts system audio into text using `faster-whisper`.
- **Local AI Integration:** Generates responses using locally hosted Ollama models.
- **Context-Aware Responses:** Accepts additional context to improve answer relevance.
- **Streaming Output:** Displays AI-generated responses as they are produced.
- **Desktop Interface:** Interactive GUI built with PySide6.
- **Response Management:** Copy or clear generated responses easily.
- **Configurable Settings:** Customize AI models and transcription parameters.

## 🛠️ Tech Stack

- Python
- PySide6
- faster-whisper
- Ollama
- soundcard

## 🎯 Goal

The goal of Interview Buddy is to combine audio transcription and AI-assisted responses in one convenient desktop application, focusing on responsiveness, usability, and local AI inference.
